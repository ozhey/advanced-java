## Solutions for Advanced Java Course, The Open University of Israel

Solutions for the assignments of **[20554 – Advanced Programming in Java](https://www.openu.ac.il/courses/20554.htm)** (תכנות מתקדם בשפת Java), developed as part of a B.Sc. course at the Open University of Israel, semester 2022A.

All assignments received a score of 100.
